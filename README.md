# Data Structures in Java

Educational Java implementations and experiments with advanced data structures.

This repository contains Java programs for tree-based data structures and hashing techniques, including B-Trees, 2-4 Trees, and Cuckoo Hashing.

## Overview

The project includes independent implementations and experiments developed for data structures practice.

Implemented topics include:

- B-Tree insertion, search, deletion, and balancing
- 2-4 Tree insertion experiments
- Cuckoo Hashing with two hash tables
- Collision handling and cycle detection in hashing
- Interactive testing through simple Java test classes

- Data Structures
- B-Trees
